# ansible-cisco-telemetry

This is a workshop built on the standard [Ansible Network Automation Workshop](https://github.com/ansible/workshops/tree/devel/provisioner) designed to get hands-on with [Cisco Model-Driven Telemetry](https://www.cisco.com/c/en/us/products/collateral/switches/catalyst-9300-series-switches/model-driven-telemetry-wp.html) and [Event-Driven Ansible](https://www.redhat.com/en/technologies/management/ansible/event-driven-ansible).

Provision the underlying workshop, then run `workshop/configure_workbenches.yml` against all the student workbenches, connecting as the `student` user.
